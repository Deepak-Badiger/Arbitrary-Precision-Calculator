# Arbitrary Precision Calculator Using C

## Project Description

Developed an Arbitrary Precision Calculator (APC) using C programming to perform arithmetic operations on very large integers that exceed the storage limits of standard C data types such as int, long, and long long.

Implemented large number representation and arithmetic operations using a doubly linked list data structure, where each node stores a digit of the number. This approach enables processing numbers of varying lengths without depending on fixed-size integer data types.

Implemented arithmetic operations such as addition, subtraction, multiplication, and division using custom algorithms. Handled carry propagation, borrowing, sign management, and digit-by-digit calculations to ensure accurate results for large integer values.

Designed the application using modular functions and dynamic memory allocation to efficiently manage large numbers and perform mathematical computations.

## Key Features
- Performs arithmetic operations on large integers.
- Supports addition, subtraction, multiplication, and division.
- Handles numbers exceeding standard C data type limits.
- Uses doubly linked lists for large number representation.
- Implements carry and borrow handling.
- Supports positive and negative numbers.
- Uses dynamic memory allocation.
- Handles different number lengths.
- Provides accurate arithmetic results through custom algorithms.

## Technologies Used
- Programming Language: C
- Data Structures: Doubly Linked List
- Concepts: Dynamic Memory Allocation, Pointers, Structures, String Handling, Arithmetic Algorithms, Modular Programming.

## Learning Outcomes

Gained practical experience in implementing arithmetic algorithms, handling large numerical values, designing linked-list-based data structures, dynamic memory management, pointer manipulation, and modular programming in C.
